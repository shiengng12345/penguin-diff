# 双语、设置与本机个人资料

用户于 2026-10-03 要求双语、参考截图的可扩展设置页，以及显示名称、默认头像选择、主题。当前实现为原生 macOS SwiftUI；继续保留三项工具与本机 MCP，不增加账号系统或生产连接。

设置入口置于主侧栏底部，也可使用 `⌘,`。用户随后明确要求设置占据整个窗口：进入后隐藏 env.js、Vault、YAML 工具侧栏，左上角提供带左箭头的“返回工具”。设置页只保留自己的通用、个人资料、外观分类，右侧显示所选分类；后续可继续增加分类。返回时保留原工具、输入与比较结果；工具视图保活，但设置打开期间禁用整个工具层及原生编辑器的编辑、选择、焦点和文本／输入法标记输入，也不暴露在无障碍树中。全部 App 窗口撤销隐藏工具焦点；返回通过独立 closeSettings 方法执行，不改工具值。返回按钮支持 Esc；设置打开时停止计算的 Esc 菜单禁用，避免把返回动作当成取消计算。使用原生控件、清晰字段标签和键盘操作，不复制截图中与本工具无关的 CMS 功能。

- 通用：简体中文和 English，首次使用按系统首个受支持语言选择，没有受支持语言时使用 English；保存选择后优先使用明确选择。切换立即生效，包括现有提示、受控错误、菜单、表格与辅助功能标签。
- 个人资料：本机显示名称，最多 40 个完整字符；过滤控制字符，保留中文与 emoji。空名称显示随语言变化的默认名称。8 个内置 SF Symbols 头像，无上传或下载。
- 外观：跟随系统、浅色、深色，以及 6 种强调色。主题应用到 App 窗口与设置页；系统模式不强制颜色方案。
- 主题由 AppKit 应用外观统一管理，系统模式解除显式外观；从浅色或深色返回系统模式时，标题栏与内容一致。进入设置前若原生编辑器已有输入法组合，结束标记并保留当前可见文本，返回时恢复有界选区；原生协议回归不等同于真实 GUI 输入法验收。
- 仅 5 项显示偏好保存到本机 UserDefaults：语言、名称、头像、主题、强调色。输入、结果、URL、Token、MCP 授权不由设置系统持久化。恢复默认只修改这 5 项。

语言、主题、头像和设置导航不能改变工具输入、过滤条件、比较结果、session、Vault 预览或授权，也不能触发网络读取。切换到另一个工具仍采用现有清空规则。配置原文、路径、文件名、精确数字、UTF-16、机器字段、状态码和 MCP 协议字段保持不变；人类可见的受控 UI 文案通过明确目录翻译，不对任意用户字符串做搜索替换。

验证包含实际本机偏好保存与重新读取、损坏设置回退、Unicode 名称边界、参数原样插入、真实 Rust 比较与错误在切换语言后保留、设置重置隔离。补实际打包 GUI 的设置导航、双语切换、个人资料与主题观察，并继续完整 Rust/Swift/HTTP/TLS/XPC/MCP 门禁。最终候选必须由 CC 和 DS 独立审核同一冻结清单；此前候选的接受结论不继承。

这份设计记录新增需求；测试与截图分别形成执行证据，不表示完整目标已经验收。
